Self-Service Documentation

COMMON QUESTIONS & GUIDES

Find immediate answers to standard technical questions and server administration tasks.

How do I connect to my server's SFTP file manager?
Open your favorite SFTP client (such as FileZilla or WinSCP). Go to the "Settings" tab in your ShadowNode Pterodactyl panel to find your SFTP Host, Port, and Username. Use your panel account password to log in. You can now drag and drop world folders, plugins, and configuration files directly.
How do I point my custom domain (e.g. play.mycommunity.com)?
In your domain registrar's DNS management (Cloudflare, Namecheap, GoDaddy):
1. Create an A record pointing to your server's numeric IP address.
2. If your server is not running on the default 25565 port, create an SRV record with Service: _minecraft, Protocol: _tcp, Priority: 0, Weight: 5, Port: [Your Server Port], Target: [Your A Record].
Which Java version should I select for Minecraft 1.20 and 1.21?
Minecraft 1.20.5 and 1.21+ require Java 21. For Minecraft 1.18 to 1.20.4, use Java 17. For 1.16.5 and older, use Java 11 or Java 8. You can switch Java runtimes with a single click in the "Startup" tab of our panel without reinstalling.
How do automated backups work?
Under the "Backups" tab in the control panel, you can trigger immediate manual snapshots or establish scheduled cron backups (e.g., every 12 hours). Backups are compressed and stored securely off-site, leaving your server disk allocation unaffected.
How do I request a refund if I experience performance issues?
We offer a straightforward 24 to 48-hour refund guarantee for initial service activations. Simply message our support staff on Discord or submit a request stating your server ID and email, and our team will process your refund promptly.
